## Features

- Usage calendar on Android: total time per day, plus time, opens and blocks for each app, kept on the phone for 365 days.
- Schedules that block chosen apps during set hours, on Android and iPhone.
- Daily time limits per app on Android, including a 0 minute limit that keeps an app closed all day.
- Open limits and a short pause before an app opens on Android, for apps you open dozens of times a day.
- Quick Focus on Android: lock distracting apps right away for a set number of minutes.
- Strict mode on Android: rules can only be relaxed with an unlock code, which you can give to a friend or family member, and Anti-Uninstall is turned on with it.
- Works for adults setting limits for themselves and for parents setting limits on a child's phone (on the child's phone itself; there is no remote management).

## Platforms

- Android: v0.1.19, APK download from the website or GitHub Releases (not in Google Play).
- iPhone (iOS 16+): v0.1.5, schedule blocking, Anti-Uninstall, clock change protection and unlock code only.
