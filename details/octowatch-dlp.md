## Overview

OctoWatch DLP is a Windows employee monitoring and data loss prevention platform for office, remote and terminal server (RDS) teams. It combines timesheets and productivity analytics with security-focused capture and rule-based blocking, deployed as a cloud service or fully on-premise.

## Features

### Time Tracking and Productivity

- Active and idle time monitoring
- Timesheets, timeline and attendance views
- Productivity categorization and analytics
- A Time Tracking edition with a narrower privacy scope

### Employee Monitoring

- Application, website and search query monitoring
- Screenshots, video recording, live view and remote control
- Activity timeline for investigations
- Windows workstations and terminal server sessions

### Data Loss Prevention

- Rules that notify or block websites, files and USB devices
- Risk alerts by email on policy hits
- Clipboard, print and removable media monitoring
- OCR content recognition (on-premise add-on)

### Platform

- Cloud web console or on-premise server and console
- Floating licenses by active tracked users
- Public REST API with a Node.js client ([octowatch-api](https://github.com/extralabs/octowatch-api))

## Use Cases

- Workforce analytics and timesheets for Windows teams
- Insider risk and security investigations
- Compliance monitoring where data must stay on-premise
- Terminal server and RDS user monitoring

## Important Notes

OctoWatch DLP is monitoring software for authorized employer use on company-owned Windows computers. Organizations should give employees notice and follow local privacy and employment laws.
