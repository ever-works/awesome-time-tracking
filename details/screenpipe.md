## Overview

[Screenpipe](https://screenpipe.com/) captures screen text and audio history locally by default, creating searchable context for reviewing work across apps and meetings.

## Features

- Search captured screen text and audio transcripts
- Recall information seen or heard during work
- Create meeting notes and work summaries with AI
- Provide selected work context to AI assistants through a local API and MCP server

## Use Cases

- Reconstruct work activity and prepare daily or weekly summaries
- Find prior meeting discussions and follow-up context
- Recall research and information across applications

## Privacy and License

Raw history stays local by default. Configured cloud AI, transcription, sync and integrations may transmit context off-device. Source code is available under the [Screenpipe Commercial License](https://github.com/screenpipe/screenpipe/blob/main/LICENSE.md), not an OSI open-source license.
