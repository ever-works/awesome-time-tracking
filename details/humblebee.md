## Overview

HumbleBee is a local-first time tracker for developers, freelancers, consultants and solo users who want to track work time without a cloud account. It has a command-line workflow and a standalone desktop GUI, both using the same local SQLite database.

## Features

- Work time stored in a local SQLite database
- CLI: start and stop timers, manage projects and tasks, and generate reports from the terminal
- Desktop GUI for projects, reports, imports and switching databases
- Import of exported Time & Bill data
- Reports with tabular export
- Apache-2.0 licensed Go/Wails application ([source code](https://github.com/grobmeier/humblebee))
